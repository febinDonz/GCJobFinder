# GCJobFinder

Government Careers Canada is a responsive, static job-discovery portal for exploring
representative federal, provincial, and territorial government job opportunities
across Canada.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Live site

https://febindonz.github.io/GCJobFinder/

The sample listings are illustrative, not live vacancies. Search, government-level
and region filters, sorting, region shortcuts, and saved jobs work in the browser.
Each listing links to its government's official careers portal. Saved jobs use
browser local storage.
