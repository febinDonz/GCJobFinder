# GCJobFinder

GC Careers is a responsive, static job-discovery portal for exploring representative
opportunities across Government of Canada departments and agencies.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

The sample listings are illustrative, not live vacancies. Search, filters, sorting,
department shortcuts, and saved jobs work in the browser; job links lead to the
official Government of Canada jobs page. Saved jobs use browser local storage.
